02 · Background

项目背景
以及当前界面现状

平台聚合开放能力、科技图谱、孵化广场、数据开放合作等多条业务入口，页面类型多、信息密度高，是典型的多角色 B 端产品。改版从界面本身出发：让层级先立住，再谈细节。

  • 导航并列过多 双层导航叠加，入口缺乏主次
  • 头部不聚焦 详情页标题、标签、操作区散落
  • 长页无节奏 内容连续铺排，分段与留白缺失
  • 双端不统一 Web 与移动端组件样式各自为政

04 · Audit

梳理界面问题，锚定设计发力点

按模块盘一遍现状，把每个问题对应到一个明确的界面动作

模块界面现状设计发力点
顶部导航双层导航叠加，并列入口多，当前态不突出收敛为一级导航 + 面包屑，并列项控制在 7 个以内，当前项用蓝色下划线标记
详情页头部标题、标签、简介、操作区分散在三个高度头部三段式：主标题 / 元信息标签 / 主操作按钮，蓝底白字只留给主操作
内容区版式长文本与卡片混排，间距不一，重心漂移统一栅格与 8px 间距基准，按「说明—示例—流程」分段留白
状态表达审批进度仅靠文字区分，扫读成本高状态色语义化：已通过 / 申请中 / 待审核，配合表头蓝底强化表格层级
移动端与 Web 端组件样式脱节，信息组织不一致资源统计卡、流程表、折叠面板与 Web 端同源，数字放大形成视觉锚点
